    ideas i keep coming back to

    • i like building software, writing about ideas, and figuring out how things work.
    • breadth first, ai native. the engineer who ships across the stack beats the one waiting for tickets.
    • own the system end to end. that's the edge.
    • features nobody uses aren't free. cut them or fix them.
    • files are the only truth. every other store is a rebuildable cache.
    • failures should be loud. a pipeline dead for weeks at log level info is lying to you.
    • make the requirements less dumb. delete. simplify. then speed up. automate last.
    • code owns the loop. the model makes typed judgments inside it.
    • agents get bounded, reversible work. never delete, never move money, one task per run.
    • a good agent is quiet by default. text me when it matters, with a link to the thing.
    • reversibility makes yes cheap. propose the write, ship the undo.
    • typed model first, llm only when it's unsure. most of the quality for a fraction of the cost.
    • what's your favourite knowledge base for agents?
    • protocols before tools. write the system down, then automate it.
    • one concrete deliverable per block beats a vague intention.
    • data is the truth i tell myself when i stop lying.
    • compounding beats intensity. anyone can do a hard week. almost nobody does a decent decade.
    • clis over guis. bun over npm. answer first.
    • operator, not hustler.
    • non-consensus ten-year ideas beat two-year clones.
    • build what you and your friends actually want. (paul graham, but true)
    • i read founders like codebases: hundreds of founders episodes, searchable.
    • fundamentals over shiny objects. kinda like kobe.
    • a colossus is a level, not an enemy.
